# Actualización segura de Cartera Dashboard

## Antes de instalar

1. Cierre completamente Cartera Dashboard.
2. Verifique que no exista el proceso de la aplicación en el Administrador de tareas.
3. Ejecute el instalador incluido en este pendrive.

## Protección de datos

- El instalador contiene únicamente la aplicación.
- No contiene bases de datos de desarrollo ni clientes de prueba.
- La base real permanece en la carpeta de datos de Windows.
- Antes de una migración, el sistema crea automáticamente un respaldo dentro de:

```text
<AppData de Cartera Dashboard>\data\backups\
```

- Si una migración falla, el sistema restaura el respaldo previo y no inicia con datos incompletos.

## Después de instalar

Verifique:

- Nombre de empresa: FreePlastic S.A.
- Usuario: Lcda. Alba Mayorga.
- Clientes y documentos visibles.
- Gestiones, promesas y abonos disponibles.
- Versión mostrada en Configuración.

No copie manualmente ninguna base de datos desde el pendrive hacia la computadora.
