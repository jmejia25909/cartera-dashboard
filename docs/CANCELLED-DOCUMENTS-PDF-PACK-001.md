# CANCELLED-DOCUMENTS-PDF-PACK-001

Agrega el botón **Exportar PDF** a Documentos Anulados.

El reporte reutiliza la matriz maestra existente:

- `createPdfContext`
- `drawPdfHeader`
- `drawPdfMetricCards`
- `savePdfDocument`
- pie de página y numeración centralizados

El PDF incluye tarjetas de Total, Anulados, Ya Anulados y No Encontrados, más el detalle histórico.
