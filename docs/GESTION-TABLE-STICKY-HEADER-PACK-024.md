# GESTION-TABLE-STICKY-HEADER-PACK-024

Ajusta la tabla principal del módulo Gestión para que el encabezado permanezca visible durante el desplazamiento vertical interno.

Cambios:

- `position: sticky` aplicado directamente a cada celda `th`;
- encabezado fijo en la parte superior del contenedor;
- tipografía de encabezados más grande y legible;
- iconos de llamada, correo, WhatsApp y documento ampliados;
- mejor contraste, sombra y separación del encabezado;
- filas ligeramente más legibles;
- scrollbar integrada y visualmente consistente.

No modifica lógica, datos ni JSX.
