# GESTION-HOOKS-FOUNDATION-PACK-015

Crea la primera capa de hooks del módulo Gestión.

Incluye `useGestionViewState`, responsable de:

- búsqueda;
- paginación;
- tamaño de página;
- selección individual y masiva;
- ordenamiento;
- restablecimiento del estado visual.

Este paquete crea la base reutilizable sin alterar todavía el comportamiento actual de `App.tsx`. La conexión con el módulo existente se realizará en la siguiente migración controlada.
