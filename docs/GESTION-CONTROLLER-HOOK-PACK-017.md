# GESTION-CONTROLLER-HOOK-PACK-017

Crea `useGestion`, el hook controlador de alto nivel del módulo Gestión.

Este hook integra:

- `useGestionViewState`;
- `processGestionItems`;
- búsqueda;
- ordenamiento;
- paginación;
- selección visible;
- exposición unificada de estado y resultado.

El paquete deja lista la capa de orquestación para conectar progresivamente `App.tsx` en el siguiente paso.
